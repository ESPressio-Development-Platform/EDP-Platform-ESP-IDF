# current-context-binding

Complete ordinary-task bind, read and exact retirement. This is not Threading instrumentation.

1. Select one surface below.
2. PlatformIO: pio run -d PlatformIO_Arduino -e esp32dev, or pio run -d PlatformIO_ESP-IDF -e esp32dev. Use esp32s3 for S3. Dependencies use GitHub URLs.
3. Arduino IDE: install ESP32 board support and the libraries from the manifests. Open Arduino_IDE/Arduino_IDE.ino with its adjacent Example.hpp and select C++20.
4. Upload and monitor at 115200 baud.

- [Arduino IDE source](Arduino_IDE/Example.hpp)
- [PIO Arduino source](PlatformIO_Arduino/src/Example.hpp)
- [PIO ESP-IDF source](PlatformIO_ESP-IDF/src/Example.hpp)

See [qualification](../../docs/CURRENT-CONTEXT-BINDING.MD). Source availability is not physical qualification.
