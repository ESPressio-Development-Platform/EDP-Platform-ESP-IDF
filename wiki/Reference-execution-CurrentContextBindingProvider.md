[Maintained target project](https://github.com/ESPressio-Development-Platform/EDP-Platform-ESP-IDF/blob/7508bb4b3b3589e7cfebc92558a2ef941852d1c3/tests/current-context/target/platformio.ini) supplies native and Arduino environments for ESP32/S3. TargetRecord.hpp defines Record::identity, Binding, ReadOtherTranslationUnit, Run; OtherTranslationUnit.cpp performs the independent-TU read. main.cpp supplies native app_main or Arduino setup/loop.

[Qualification.cpp](https://github.com/ESPressio-Development-Platform/EDP-Platform-ESP-IDF/blob/7508bb4b3b3589e7cfebc92558a2ef941852d1c3/tests/current-context/target/src/Qualification.cpp) contains fixture-only Print/Flush/Require; binding, controllerRecord, records, controls, stacks; Entry (record/bit/controller/abrupt) and entries; WaitBits, AwaitParked, DeleteParkedTask, TaskEntry, TimerCallback; migrationStacks/migrationControls/hogs/migrationController/applicationController/migrationRecord, HogEntry, MigratingEntry, MigrationControllerEntry, CheckMigration; executionControl/executionStack, ExecutionArguments (provider/record), ActualOwnerEntry, CheckActualExecutionOwner, Run. All busy load loops, notifications and waits are test infrastructure, never probe implementation. Static TCB reuse requires observed stable nonexecution before deletion; a completion notification alone is insufficient.

Target fixture additionally owns one selected timebase and canonical clock plus MeasureLookup. Seven 100000-iteration bound and unbound samples use Clock::MonotonicClockProvider; diagnostics run outside measured loops. Report nominal elapsed batches and a matched empty-loop baseline, not total probe cost or worst-case latency.
