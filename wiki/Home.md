# EDP-Platform-ESP-IDF Developer Wiki

EDP-Platform-ESP-IDF provides ESP-IDF concrete providers for EDP-Platform, EDP-Memory and EDP-Security where ESP-IDF owns the underlying API.

This Wiki is maintained beside the code on `main`. Source code and repository `docs/` remain normative; the Wiki is the internal developer explanation/navigation layer.

## Public entry point

```cpp
#include <ESPressio_Platform_ESP_IDF.hpp>
```

## Dependencies

Mandatory: EDP-Platform, EDP-Memory and EDP-Security.
